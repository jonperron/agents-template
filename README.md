# agents-template

All the md files/skills/rules/agents I use

## Third party libraries

- [coderabbit](https://www.coderabbit.ai/) to review the changes from Claude
- [openspecs](https://openspec.dev/) for spec driven development (mauve-viewer)
- [openwiki](https://github.com/langchain-ai/openwiki) to use as memory files for the agents.
- [rtk](https://github.com/rtk-ai/rtk) to reduce amount of token used by commands
